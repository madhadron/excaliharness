# T-007: Create the Quick reference task when it's missing

* status: draft

## Description
When the README or its `# Quick reference` section is missing, create an infrastructure task to write it, so other tasks wait on it.

## Context
[[docs/decisions]] D-020, D-012, D-042.

## Issue
Today a missing Quick reference means a task runs with no gates at all.

## Expectation
The orchestrator creates a draft `kind: infrastructure` task to write the section, once, with a diagnostic pointing at the README; other tasks then wait on it.
