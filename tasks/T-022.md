# T-022: Stop the agent's whole process tree

* status: draft

## Description
Make sure stopping an agent's `docker compose run` also stops a Compose plugin that survives the SDK's single signal.

## Context
[[docs/roadmap]] (Security: the SDK path's process tree), D-079.

## Issue
A surviving plugin could keep a round from ending.

## Expectation
The agent's process is spawned in its own process group and the whole group is stopped, as `exec.ts` already does for other commands.
