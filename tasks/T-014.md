# T-014: Build dev images to an ID

* status: draft

## Description
Read the dev image's ID from the build itself instead of inspecting its tag afterwards.

## Context
[[docs/roadmap]] (Runner housekeeping), D-052.

## Issue
Two tasks building a dev image with the same `image:` name at once can swap the tag between build and inspect.

## Expectation
Each build reports its image ID (e.g. an iidfile via a bake or buildx call), and nothing reads the tag.
