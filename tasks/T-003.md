# T-003: Chat participant for change requests

* status: draft
* depends_on: [[T-001]]

## Description
A VS Code chat participant (`@task T-NNN ...`) that takes larger change requests for a task under review.

## Context
[[docs/decisions]] D-014. Requests go through the same round loop as findings (D-072).

## Issue
Change requests too large for a line comment have no route back to the agents.

## Expectation
`@task T-007 also handle expired links` adds the request to the task and sends it back to the implementer, with the chat showing the task's status and a link to it (D-023).
