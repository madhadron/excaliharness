# T-024: "Send back to agent" CodeLens for needs-human tasks

* status: draft

## Description
When a task is `needs-human`, show a "Send back to agent" CodeLens above its status line that hands the task back to the agents.

## Context
[[docs/decisions]] D-041 (every capability is discoverable), D-043 (status changes from the editor), D-076 (parked tasks), D-080 (approving a rebuild), D-083 (marking a needs-human task ready starts the round count again). The lenses are in `src/statusLens.ts`.

## Issue
Today the only way back from `needs-human` is "Mark ready", which doesn't say that it sends the task back to the agents, approves a pending rebuild, and starts three more rounds.

## Expectation
On a `needs-human` task (not a parked one), the CodeLens reads "Send back to agent" in place of "Mark ready" and does the same: `needs-human → ready`, with what that implies under D-080 and D-083. A matching command is in the command palette. "Mark done" stays next to it. Tests cover the lens on `needs-human`, `draft` and parked tasks.
