# T-006: UI design step (in-ui-development)

* status: draft
* depends_on: [[T-005]]

## Description
UI tasks go through `in-ui-development`: a designer agent drafts the design, the human iterates on it and approves it by setting `design:`, and the implementer builds from it.

## Context
[[docs/decisions]] D-013, D-008 (pipelines), D-037. Depends on what [[T-005]] finds.

## Issue
Pipelines have no design role, and the `in-ui-development` status is never used.

## Expectation
A pipeline's `design:` role runs the designer agent for tasks using that pipeline. The task waits in `in-ui-development` until the human sets `design:`, then the implementer gets the design as context.
