# T-027: Keep agent transcripts for review

* status: draft
* depends_on: [[T-010]], [[T-001]]

## Description
Save each agent turn's activity log, cleaned, in the extension's storage, and link it from the round's Updates line, so the review UI can show why the agent did what it did.

## Context
[[docs/decisions]] D-023, D-079 (agent text is cleaned where it enters), D-083 (round lines in Updates). The review UI is [[T-001]].

## Issue
Once a round ends, what the agents did and why is lost; only the commit and the findings remain.

## Expectation
Each turn's transcript is saved as plain text with a size cap, linked from its round line in Updates and from the review view, and removed by a retention rule.
