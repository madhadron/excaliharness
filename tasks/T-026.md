# T-026: Controls on a running agent

* status: draft
* depends_on: [[T-010]]

## Description
Actions on each row of the Agents pane: stop the agent, open its log, open its worktree, open its task, and send it a note.

## Context
[[docs/decisions]] D-041, D-079 (changing a running task's status already cancels it), D-083. [[T-024]] asks the same question about notes for "Send back to agent".

## Issue
Stopping an agent today means editing its task's status by hand.

## Expectation
Stop cancels the turn and moves the task to `needs-human` with "stopped by you". Open log, worktree (untrusted window) and task work from the row. Send a note adds the human's text to the agent's next turn, recorded in the task's Updates.
