# T-025: Show a running task's changes live

* status: draft
* depends_on: [[T-010]]

## Description
A "Show changes" action on a running task's row that opens the worktree's diff against where the task started, read-only and refreshed as the agent edits.

## Context
[[docs/decisions]] D-069, D-079 (the worktree lives in the extension's storage; host git uses its safe configuration and never reads agent-written config), D-084 (an opened worktree stays untrusted).

## Issue
Today the human sees an agent's changes only after the round is committed and reviewed.

## Expectation
The diff opens in a read-only view and refreshes while the agent works, using the same safe host git as commits, so the human can catch an agent heading the wrong way mid-round.
