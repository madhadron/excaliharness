# T-004: Approve merges the task branch

* status: draft
* depends_on: [[T-001]]

## Description
An Approve button on a review that merges `task/T-NNN` into the main checkout's branch and marks the task `done`.

## Context
[[docs/decisions]] D-014, D-069. Roadmap security: statuses arriving through git are accepted as they are (D-047), and merges must treat a committed `.gitattributes`, `.gitmodules`, Dockerfile and README gates as untrusted.

## Issue
Today the human merges by hand, outside the extension.

## Expectation
Approve merges with host git under the same safe configuration as commits, refuses a merge that changes `tasks/`, `TASKS.md`, `agents/` or `docs/decisions.md`, shows what the merge changes in build inputs and gates, then sets `done` and removes the worktree.
