# T-015: Faster nested-repository scan

* status: draft

## Description
Make the scan for nested `.git` folders asynchronous, and skip directories git ignores, so big `node_modules` trees don't block the worker.

## Context
[[docs/roadmap]] (Runner housekeeping), D-079.

## Issue
The scan walks the whole worktree synchronously before host git calls; vendored trees that contain `.git` block a task.

## Expectation
The scan doesn't block the worker's event loop, still fails closed, and has a test with a large tree.
