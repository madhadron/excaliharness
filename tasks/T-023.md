# T-023: Support malicious target repositories

* status: draft

## Description
Run a target repo's Compose services from an allowlist of settings, and start the proxy outside its Compose file, so a hostile repo can't escape.

## Context
[[docs/roadmap]] (Security: malicious target repositories), D-059, D-079, D-085.

## Issue
Out of scope so far: a malicious repo's own services can already reach the Docker socket.

## Expectation
A proposal first (threat model, what runs on the host), then the dev and other services built by construction from an allowlist, and the proxy created through the Engine API.
