# T-020: Check Docker's proxies config for leaks

* status: draft

## Description
Check whether the `proxies` section of `~/.docker/config.json` reaches agent containers as `HTTP(S)_PROXY`.

## Context
[[docs/roadmap]] (Security: Docker's proxies config), D-079.

## Issue
Compose reads that config, so a host proxy URL and its credentials could reach agents.

## Expectation
An experiment result, and if it leaks, Compose run with a config that has no proxies section.
