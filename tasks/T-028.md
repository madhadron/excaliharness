# T-028: Token and cost totals per task

* status: draft
* depends_on: [[T-010]]

## Description
Totals of tokens, cost, turns and time per task and per round, shown in the Agents pane and in the round lines of the task's Updates.

## Context
[[docs/decisions]] D-083 (round lines). The SDK's result message carries usage and cost for each turn.

## Issue
There's no way to see which tasks were expensive, or to tune turn limits and pipelines from real numbers.

## Expectation
Each round line in Updates gains its totals (e.g. "round 2: gates passed; 1 finding (0 blocking) · 41 turns, 1.2M tokens, $3.10"), and the pane shows running totals per task.
