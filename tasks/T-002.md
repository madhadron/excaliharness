# T-002: Line comments on a task's review

* status: draft
* depends_on: [[T-001]]

## Description
Let the human leave line comments on a task's diff with the VS Code Comments API, and send them back to the implementer as the next round's findings.

## Context
[[docs/decisions]] D-014, D-072, D-083. Findings already reach the implementer as `Finding` objects (`src/worker/runner/findings.ts`).

## Issue
The human can edit the worktree directly, but can't ask for changes without doing them by hand.

## Expectation
Comments on the review diff are kept with the task. A "Send to implementer" action turns them into blocking findings, moves the task back to `ready`, and the next round fixes them.
