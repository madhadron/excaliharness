# T-016: Let the implementer fix a failed approved build

* status: draft

## Description
When an approved image build fails on an ordinary task, run the implementer in the last good image with the failure as a gate failure, as infrastructure tasks do.

## Context
[[docs/roadmap]] (Runner housekeeping), D-080, D-085.

## Issue
Today the task goes to `needs-human` and the human has to fix the branch by hand.

## Expectation
The failed build's output reaches the implementer, who can fix the Dockerfile; approval is still needed for the next online build.
